# AV1-Video-Coding
Thanks to a new codec called AV1, or AOMedia Video 1, which was developed by the Alliance for Open Media (AOM) which consists of Google, Microsoft, Mozilla, Adobe, Amazon, and a whole list of other big hitters in the industry, services like Stadia, YouTube, and Google Duo have been able to improve live streaming, video calling via RTC, and more.
